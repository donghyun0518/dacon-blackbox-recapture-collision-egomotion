## 1. 문제 정의

| 항목 | 내용 |
|---|---|
| 대회 | 블랙박스 영상 기반 지능형 고의사고 분석 모델 AI 경진대회 (DACON 236753) · 2026.08.26–09.30 · 1인 |
| S1 재촬영 | 영상 1편 → ORIGINAL / RERECORDED. 다른 화면에 띄운 영상을 별도 기기로 다시 찍은 것만 해당(화면 녹화 제외) |
| S2 사고 시점 | 프레임 폴더 → collision_frame · entry_frame · entry_side(LEFT/RIGHT) · evasion_space(0/1). 전부 자차가 직접 충돌한 사고이고 **영상마다 FPS가 다름** |
| S3 자차 거동 | 10Hz 실차 주행 영상(무사고) → 프레임별 가감속 4클래스(ACCELERATING/DECELERATING/CONSTANT/STOPPED) · 조향 3클래스(LEFT/직진/RIGHT). 정답은 CAN 차속·종가속도와 조향각에서 만들며 임계값은 비공개 |
| 데이터 | 학습 데이터 미제공 · 공개 예시는 형식 확인용 소수 → 학습 데이터 전부를 외부 공개 데이터로 구성 |
| 제약 | 코드 제출 · L40S 1장 60분(로딩 포함, S1→S2→S3 순차) · zip 10GB · 인터넷 차단 · 하루 3회 · **파일 단위 독립 예측(규칙 2-4)** · 평가 데이터로 튜닝·Pseudo-Labeling 금지(규칙 2-3) |

### 평가 지표
```
종합 = 0.2·S1 + 0.4·S2 + 0.4·S3                    (팀 최고 종합 자동 선정 · Private = Public)
S1   = Macro-F1{ORIGINAL, RERECORDED}
S2   = 0.35·충돌 Acc@±0.3s + 0.35·진입 Acc@±0.3s + 0.15·진입방향 Macro-F1 + 0.15·회피공간 Macro-F1
S3   = 0.7·가감속 Macro-F1 + 0.3·조향 Macro-F1      (정답 STOPPED 프레임은 조향 채점 제외)
```
- 실효 배점: S3 가감속 **0.28** > S1 0.20 > S2 충돌·진입 각 0.14 > S3 조향 0.12 > S2 방향·회피 각 0.06
- S2 프레임은 영상별 프레임–시간 대응표로 **초 단위로 바꿔** 비교한다 → 학습 때 fps와 평가 fps가 다르면 같은 모델도 틀린다
- Macro-F1은 "정의된 전체 범주" 기준이다. (S2 평가 규정) 누락 행, 범위 밖 프레임, 허용 범주 밖 값은 에러가 아니라 **오답**으로 채점된다. 단 Stage 출력이 통째로 비면 제출 에러다
- 팀 최고 종합점수가 자동 선정되므로 탐침 제출에는 비용이 없다 → **리더보드를 계측기로 쓸 수 있는 구조**
- 학습 데이터가 없고 예시는 평가셋이 아니다 → 로컬 검증이 원천적으로 약하다. 이것이 모든 결정의 출발점이었다

## 3. 접근

### 3-1. S1 재촬영 판별 — 0.3181 → 0.8112
```
mp4 → 16프레임 × 최대 6타일 (384 크롭, 네이티브 화소 스케일)
   → EfficientNetV2-S 재촬영 CNN (v3b) → 타일·프레임 평균 확률 p
   → p ≥ 0.160767 ─────────────────────────────────────→ RERECORDED
   → 그 외: lap_ratio(σ 0.5, 16프레임 중앙값) < 2.800222 ─→ RERECORDED   (OR 게이트)
   → 나머지 ORIGINAL          파일 단위 독립 · 폴백: CNN → 포렌식 → 전량 ORIGINAL
```
| 구성 | 내용 |
|---|---|
| 학습 코퍼스 | 실제 화면 재촬영 데이터: 코퍼스 19세션 / 7,287프레임(홀드아웃 포함) 중 학습은 **VDmoire iPhone rig + UHDM 13세션** · 홀드아웃은 미관측 rig(vdm_tcl) 전체 + UHDM 4세션(세션 단위) |
| 전달 증강 | **양 클래스에 똑같은** H.264 전달 그리드 (v2에서 9변형으로 도입 → 직접 촬영한 C01–C06 전이 세트에서 ORIGINAL recall 0.500 → 0.817 [로컬]. v3a부터는 같은 평면을 3점(s100_crf23 · s067_crf28 · s044_crf33) + scale 지터 0.55–1.00으로 덮음) |
| 백본 | tf_efficientnetv2_s.in21k_ft_in1k (20.2M, Apache-2.0) · bs 48 · lr 1e-4 cosine · 16에폭 · TorchScript 80.5MB · 파일당 0.572초 |

### 3-1a. 모델 도입 다음의 도약 — 리더보드를 정수 계측기로
- 상수 ORIGINAL 예측의 Macro-F1은 닫힌 형태 n_O/(n_O+N)이다. 이걸로 푼 첫 역산 125:143은 **틀렸다**("원본 +k와 FP +k"가 같은 점수를 내는 퇴화 때문)
- 원본 100–169 × 누락 0–5를 전수 탐색했다. **원본 126 · 재촬영 142 · 원본 1행 상시 오답** 조합만 모델 점수 9개를 전부 유일한 정수해로 재현했다(잔차 ≤ 4.3e-11). 이후 나온 점수 3개도 같은 구성으로 다시 확인됐다
- 그 뒤로는 제출 1회마다 정확한 (FP, TP)가 나왔다: 0.247 **(2, 71)** → 0.194 **(6, 89)** → 0.161 **(13, 101)** → +lap **(17, 109)**
- 이 판독이 판단을 뒤집었다. eval 원본 FPR은 대시캠 대리집합의 **약 1/5**이었다(0.048 vs 0.22). 그래서 "임계값 레버는 소진됐다"는 판단을 철회했다 → 로짓-정규 2점 적합으로 1편의 가치를 계산(재촬영 1편 +0.0040 / 원본 오탐 1편 −0.0036) → 1차원 선 탐색
- 판독 규칙은 결과 전에 정했다. lap OR는 채택 기준(S1 > 0.7960)과 별도로 ΔTP ≥ ΔFP+2이면 기전으로 인정하기로 했고, 예측 (5.6, 8)에 실측 **(4, 8)**로 채택(0.8112)·기전 인정됐다. 6시드 앙상블은 사전 등록한 채택 기준(S1 > 0.8112)과 기전 기준을 모두 통과하지 못해 기각했다(실측 (8, 87), 0.7597)
- lap은 로컬 판별력이 거의 없었다(heldout 5.7% vs 4.3%). 그런데 eval에서는 CNN이 놓친 재촬영 41편 중 8편을, 원본 112편 중 4편을 오탐하는 대가로 되찾았다
- 한계: 로컬 재현율 ≈0.9 vs eval ≈0.5. 처음 보는 장비(Axon 0.932 · Receipt 0.965)와 전환 프레임은 원인이 아니었다. 높은 디스플레이/전달 화소비, 정면·어두운 촬영은 일부만 설명한다. 원본 1행이 늘 오답이 되는 원인도 찾지 못했다(고치면 +0.002–0.004로 추정)

### 3-2. S2 사고 핵심 시점 — 0.1466 → 0.4998
```
프레임 폴더 (영상마다 FPS 다름)
   → gray · 프레임 차분 · RAFT-small 광류(x, y) 4ch, 176×320
   → CollisionNet v2: FrameCNN → 2층 BiGRU → 프레임별 충돌·진입 로짓 → argmax ─→ collision_frame · entry_frame
   → 예측 충돌 중심 60프레임 창 → SideNet(gray+diff 112×200) + 좌우반전 TTA ────────→ entry_side
   → 충돌 −15 / −5 / 0 프레임 컬러 3장 → Qwen3-VL-2B 사실형 질문
     로짓(Yes) − 로짓(No) ≥ −0.4375 ──────────────────────────────────────→ evasion_space
```
| 구성 | 내용 |
|---|---|
| 충돌 데이터 | Nexar Collision Prediction positive 748클립(train 624 / val 124) · 1280×720@30fps · 사고 시점은 주석자 10명의 중앙값 · 진입 라벨은 time_of_alert로 대신함 |
| CollisionNet v2 | v1에서 이어학습 · 배치마다 **fps ~ U[6, 30] · 창 길이 3–30초 · 창 안 충돌 위치 10–97%**를 무작위로 · 라벨을 **초 단위로**(σ 충돌 0.2s / 진입 0.3s) · alert가 창 시작보다 앞이면 진입 = 첫 프레임 · EMA 0.998 · 141분 |

### 3-2a. 모델 도입 다음으로 큰 도약 — 학습/추론 형식 불일치 제거 (+0.1421, 제출 1회; 가장 큰 계단은 v1 도입 +0.1584)

### 3-3. S3 자차 거동 — 0.5956 → 0.7328
```
mp4 → 10Hz 디코딩 (sample_index 개수 = 디코딩 프레임 수, 컨테이너 fps 메타는 무시)
   → gray · 프레임 차분 · RAFT-small 광류(x, y) 4ch, 144×256      (RAFT 고정, 6회 반복)
   → 4층 FrameCNN + GAP → 2층 BiGRU(128) → 회귀 헤드 4 + 보조 분류 헤드(가감속 4 · 조향 3)
   → 영상 전체를 한 번에 추론(청크 3000) → 분류 헤드 로짓
   → 가감속: [원본 + 좌우반전] 로짓 평균 − 1.36·log_cw_accel → argmax
   → 조향  : 원본 로짓 − 3·0.5·(−ln f_L,S,R)                  → argmax
```

|---|---|
| 학습 데이터 | comma2k19 (MIT) 2,035세그먼트 · 20fps → 10Hz · 144×256 흑백 · 가속도는 CAN 차속을 np.gradient로 미분(평활 없음) |
| 라벨 | STOPPED 속도 < 0.5 · ACC/DEC ±0.30 · 조향은 중심 +1.0° 대비 ±3.5° (이 임계값들은 초기에 공개 예시로 보정했다) |
| 학습 | 가중 MSE + 0.5·CE, 클래스 가중 w = (1/f)^0.5 · EMA 0.997 · 좌우반전(조향 부호 반전) · 밝기 지터 · window 48 · bs 24 · 100에폭 → best ep96 |
| 가중치 | 09-05 학습본 하나를 **최종까지 고정** — 이후 재학습한 모델(phys · accel_dn · MViTv2-S E4)은 eval에서 모두 졌다 |

### 3-3a. 가장 큰 도약 — 사전확률 되돌리기 (가중치 고정, 디코드만 바꿔 +0.0538)
- 학습 때 희소 클래스를 키운 가중 CE를 추론 때 되돌리면 eval이 올랐다. 가감속·조향 두 헤드 모두에서 확인됐다. α1은 해석적 역보정(자유파라미터 0)이고, α3·K 1.36·조향 TTA 해제는 eval로 고른 값이다
- 가감속 α 0 / 1 / 1.36 / 2 = 0.6243 / 0.6791 / 0.6816\* / 0.6703 → α1의 몫 +0.0548, 1.36에서 포화(추가 이득 ≤ +0.0002)  
  <sub>\* K(α 1.36)는 조향 α3 조건에서 측정한 값을 헤드별 정확 분해로 같은 좌표에 환산</sub>
- 조향 α 0 / 1 / 2 / 3 / 4 = 0.6853 / 0.7057 / 0.7238 / 0.7303 / 0.7235 → α3의 몫 +0.0450 (X 대비)
- 조향 쪽 기전 가설: 좌우반전 증강 때문에 실효 분포는 L/R 대칭인데 클래스 가중은 비대칭이라 LEFT 쪽으로 ≈ +0.39 로짓 편향이 생겼다(0.5·ln(0.191/0.088))
- Track A 0.6791 → 0.7328 = **+0.0538**: 조향 +0.0512 (조향 F1 **+0.171**) · 가감속 +0.0025 (F1 +0.0036)
- "희소 클래스를 더 예측하라"는 Macro-F1 직관과 **정반대**였다. 역보정을 없앤 α0은 +0.03–0.07을 예상했지만 eval에서 −0.0548이었다

## 7. 배운 것
- **리더보드는 목표가 아니라 정수 계측기다** — 닫힌 형태의 Macro-F1과 10자리 점수로 비공개 평가셋 구성(S1 126/142/누락 1, S2 137·92·87)을 복원했고, 이후 제출마다 (FP, TP)를 읽었다
- **자유파라미터 0개 변경은 예외 없이 전이됐다** — S2 형식 불일치 제거 +0.1421, S3 해석적 사전확률 역보정(Track A +0.0438, 조향 α1 +0.0204), S1 무학습 lap +0.0152. 가장 큰 단일 이득은 학습된 모델(S1 v3b +0.3965, S2 v1 +0.1584)에서 나왔지만, 로컬 지표에 맞춰 고른 변경은 전이되지 않았다
- **로컬 점수로 기각하지도, 채택하지도 말 것** — 로컬 판별력 0이던 lap은 eval에서 통했고, 로컬 1위였던 E4·6시드 앙상블·불변성 손실은 eval에서 졌다
- **"모델이 무작위"처럼 보이면 추론 방식부터 의심하라** — SideNet 가중치는 그대로 두고 적용 창을 예측 충돌 중심 60프레임으로 바꿨더니 eval F1이 0.505 → 0.771로 올랐다(창 중심은 같은 제출에서 바뀐 v2 충돌 예측, v1 창 효과는 미측정)
- **학습 데이터의 '재촬영'은 진짜여야 한다** — 합성 열화는 우연 수준이었다. 실제 화면 재촬영 코퍼스를 쓰고 양 클래스에 같은 전달을 걸어야 했다
- **공개 예시는 평가셋이 아니다** — 예시로 정한 방향 하나 때문에 제출 2회를 잃었다. 예시는 형식 확인에만 쓴다
